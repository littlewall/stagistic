# Product

## Register

product

## Users

Wave 1: playwrights and librettists — writers working alone or in collaboration, deep in drafting or revision. They sit down to write a full-length theatrical script: structured acts and scenes, dialogue, stage directions, and (for musicals) lyrics and musical numbers. The tool is the only thing on screen.

Future waves: connected apps for production teams — stage managers, marketing, directors — using the same script as a shared source of truth. Those surfaces have their own register and requirements; this document governs the core editor.

## Product Purpose

Stagistic is an open-source, cloud-capable script editor built specifically for theatre and musicals. It structures a script the way theatre structures it — acts, scenes, stage directions, characters, musical numbers — rather than adapting a screenwriting or general-document tool. The core editor is free, now and permanently. Production management features built on top may become paid. Success looks like a playwright finishing a full-length script and handing a director a correctly-formatted PDF without touching a second tool.

## Brand Personality

Quiet, precise, theatrical.

The interface carries the discipline of a prompt book: every element earns its place. It is aware of the art it serves without announcing itself. Warm references: iA Writer (editorial clarity, writer-first focus), Notion Docs (calm, structured, low visual noise).

## Anti-references

- **Heavy SaaS dashboards** (Jira, Asana, enterprise PM tools): dense sidebars, data tables as defaults, feature-heavy navigation. Stagistic is a writing instrument, not a project tracker.
- **Gamified or cluttered writing apps** (Scrivener-style multi-panel complexity, reward-badge UIs): visual busy-ness that pulls attention from the script. No panels for the sake of panels.
- **Loud marketing / AI landing pages**: purple gradients, hero-metric grids, feature carousels, buzzword copy, identical card grids. The landing page should feel as precise as the product.

## Design Principles

1. **The script is the center.** Every UI decision is measured against whether it serves or distracts from the act of writing. When in doubt, subtract.
2. **Theatrical without theatrics.** The interface carries the precision of a prompt book, not the noise of a poster. Structure and restraint over decoration.
3. **Structure is a first-class feature.** The theatrical hierarchy — acts, scenes, characters, musical numbers — is meaningful data, not just formatting. Make it visible without overwhelming the page.
4. **Compose, don't sprawl.** The editor must sit comfortably next to future production management apps without becoming a dashboard itself. Surfaces grow by composition, not by adding more to one screen.
5. **Professional discretion.** The tool doesn't announce itself. No onboarding fanfare, no empty-state cheerfulness. A playwright picks it up and gets to work.

## Accessibility & Inclusion

No formal WCAG certification target at this stage. Good practices apply throughout: sufficient contrast, keyboard navigation, and reduced-motion support.

Desktop-first for all app surfaces (wave 1). The landing page supports both desktop and mobile.
