# Better Auth Migrations

This directory contains auto-generated Better Auth migration files.

## About

- Migration files are **SQL scripts** generated by Better Auth CLI
- Files are **automatically applied** and then can be deleted
- These files are **not committed** to the repository (see `.gitignore`)

## File Naming

Migration files follow the pattern:
```
YYYY-MM-DDTHH-MM-SS.sssZ.sql
```

Example: `2025-10-02T10-51-28.510Z.sql`

## How It Works

1. Run `make dev-auth-generate` - generates SQL file here
2. Run `make dev-auth-migrate` - applies the migration to database
3. Files can be removed after application (or kept for reference)
