---
title: Add introductory pages
description: Include characters, places, contents and vocal ranges before the script.
---

You want the cast to find the characters and scenes of `The last door` before they start reading. Choose which introductory pages this PDF needs.

## Include the pages you need

1. Choose **Export** in the app header.
2. Expand **Opening pages** in the export controls.
3. Turn on **Characters**, **Places**, **Contents** or **Vocal ranges**, as needed.
4. Wait for the preview to update, then check the pages before the script.

These are choices for the current export. For this PDF, set the options directly in Opening pages, including character order and outlines; opening the separate Initial pages panel in Script settings does not select which pages this export includes.

## Prepare a character and place overview

With **Characters** on, choose **Order characters by**: **name** or **first appearance**. Use **Show character outlines** to include the descriptions stored with the characters.

The list uses confirmed characters, including confirmed characters you have created but not yet used. If a name or outline is missing, [confirm the character](/editor/characters/confirmation/) or [edit its details](/editor/characters/manage/). Groups help identify speakers but are not separate entries in this character list.

**Places** uses places assigned to scenes, ordered by their first scene appearance. Merely creating a place without assigning it to a scene does not add it to this overview. See [Edit scene details](/editor/structure/details/) to check those assignments.

## Add contents for scenes, music or both

With **Contents** on, choose **Show**:

- **scenes** for scene navigation;
- **musical numbers** for the music list;
- **scenes and musical numbers** for both.

The overview follows the script's structure and uses references to the resulting output. For music, it lists open musical numbers rather than point **Hits**. If a heading or number needs attention, edit it in [Acts and scenes](/editor/structure/) or [Music and lyrics](/editor/music/), then check the updated preview.

When exporting selected characters, Contents follows the scenes included by that filter. Characters, Places and Vocal ranges still use the script's overview data; they do not automatically become a list limited to your selected character.

## Add vocal ranges

Turn on **Vocal ranges** for a vocal overview. A character needs a valid lower and upper vocal-range note in their [character details](/editor/characters/manage/) to appear. Voice type can accompany the range.

If there are no characters with both range endpoints, enabling the option does not produce a vocal-range page.

## Number and align the introductory pages

**Show page numbers** adds Roman page numbers to the introductory pages. **Start each initial page on an odd page** aligns the beginning of each introductory section and can add blank pages between sections.

For blank pages between this material and the script, see [Control page breaks and blank pages](/editor/export/page-breaks/).
