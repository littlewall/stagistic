title: Set up script pages
description: Choose the paper and margins, then adjust the appearance of a script block type.
---

You want an A4 copy of `The last door` with enough room for rehearsal notes. Set up the page first, then adjust Dialogue if its spacing or width needs attention.

## Choose the paper and margins

1. In the app header, use <img class="kb-editor-icon" src="/icons/editor/settings.svg" alt="" aria-hidden="true" /> **Open script settings**.
2. Choose **Page layout** in the settings sidebar.
3. Under **Page size**, choose **A4** or **US Letter**.
4. Adjust **Top margin** and **Bottom margin**. Their choices are expressed in rows.
5. Drag the **Left page margin** and **Right page margin** handles below the page diagram. Check the displayed left/right margins and content width.
6. Choose **Close settings**, then [check the PDF preview](/editor/export/pdf/).

The diagram shows the space available for the script, header and footer. Narrowing the content area or increasing vertical margins can move writing onto additional pages.

Changes apply as you make them and are saved automatically for this script. They also apply to later exports; they are separate from the temporary choices in the export panel.

## Adjust Dialogue as a block type

1. Open Script settings again.
2. Expand **Block settings**, then choose **Dialogue**.
3. Use the handles around the sample text to adjust its left and right indentation.
4. Choose **Line height** for the space between lines and **Spacing before** for the gap before a Dialogue block. Some block types also offer **Spacing after**.
5. Check the sample, close settings and inspect the result in the script and PDF preview.

This changes the default appearance of Dialogue throughout the script. Other types, such as Character, Aside and Lyrics, have their own Block settings pages.

Use the formatting controls above the sample when you want to change a block type's default text style. For styling particular words instead, see [Format text](/editor/writing/formatting/).

## Restore a block's defaults

If a block type has custom settings, its page offers **Reset**. This restores that type's settings, including its appearance, shortcut and next-element choice. Use it when you want to reset the whole type; for a single spacing change, adjust that field directly.

The default settings of other block types are independent. For what happens when you continue writing, see [Customize your writing flow](/editor/writing/customize-flow/).
