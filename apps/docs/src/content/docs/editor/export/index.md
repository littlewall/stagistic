## Start with the output you need

For a straightforward copy, choose **Export** in the app header, use the **Basic** template and check the PDF preview before downloading. You can return to each setting when you need it; these articles are independent tasks.

**Script settings** holds the document's page layout, block appearance, title-page details and headers/footers. Changes apply as you make them and are saved automatically. **Export** holds choices for the current PDF, including the template, character selection, opening pages and page flow.

Switching between Basic and Integrated score keeps your current export choices. Leaving Export and opening it again starts with Basic and its default choices; the document's saved settings remain.

For an editable copy or backup with metadata and attachments, see [Download a script file or package](/editor/scripts/download/).
