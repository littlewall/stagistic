---
title: Export for selected characters
description: Include the scenes needed by selected characters, with optional preservation of full-script pagination.
---

Alex needs the scenes in which he appears for rehearsal. Prepare that selection while keeping the surrounding dialogue and stage directions useful.

## Choose the characters

1. Choose **Export** in the app header.
2. Expand **Content** and turn on **Selected characters only**.
3. Check **Characters to export**. When you first enable the filter with no saved selection, all available characters are selected.
4. Leave Alex selected and deselect the characters whose scenes you do not need.
5. Wait for the preview to update and check the included scenes.

The filter keeps **whole scenes** that mention a selected character, plus their act headings. It keeps other speakers' dialogue and the remaining blocks within those scenes. It does not produce a sheet containing only Alex's lines.

A linked character reference in a stage direction can make a scene match even if that character has no speech there. A reference to a character group also counts when the selected character is a member of that group. Shared speaker blocks can match any of their selected speakers.

The chooser lists confirmed individual characters. If Alex is missing, [confirm him](/editor/characters/confirmation/) first. To check a group's membership, see [Work with character groups](/editor/characters/groups/).

## Keep page references aligned

Leave **Preserve full-script pagination** on when Alex and the rest of the cast need to refer to the same pages.

The PDF keeps the original page references and the text's positions within retained pages while hiding excluded scenes. A partly retained page can have empty areas where excluded text used to be.

Pages containing only excluded script content are omitted. Inserted alignment blanks can remain, and the printed page references can have gaps. Use those references to compare with the complete copy; the PDF's Page counter may differ.

This comparison uses the current export choices, including Show notes and Page flow. Use the same choices for the complete copy when you need matching references.

Turn Preserve full-script pagination off for a compact copy that lays out only the retained scenes again. The scenes move together and page references can change.

## Check an empty or unexpected selection

If no characters are selected, the filter has no scenes to retain. Select at least one character, or turn off Selected characters only to return to the complete script.

If a scene is included unexpectedly, look for a character reference or group containing a selected character as well as speaker names. The filter operates on the scene's references, not only on who has a solo line.

## Check introductory pages too

[Contents](/editor/export/initial-pages/#add-contents-for-scenes-music-or-both) follows the retained scenes. Character, place and vocal-range overviews still use the script's overview data, so check whether you want those pages in this actor's copy.

After checking both the selection and pagination, [download the PDF](/editor/export/pdf/).
