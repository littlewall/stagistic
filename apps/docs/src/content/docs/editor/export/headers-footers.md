title: Set headers and footers
description: Add running text and draft information, and format the script's page references.
---

You want the title and draft date on the script pages of `The last door`, so readers can identify loose rehearsal sheets.

## Add information to an area

1. In the app header, use <img class="kb-editor-icon" src="/icons/editor/settings.svg" alt="" aria-hidden="true" /> **Open script settings**.
2. Choose **Header and footer**.
3. Click the **left header** area in the preview. Selecting an area enables its controls.
4. Choose **Script title** to insert the current title.
5. Click the **left footer** area and choose **Draft date**.
6. Close settings and [check the PDF preview](/editor/export/pdf/).

You can write ordinary text in **Header or footer content** or combine it with a variable. For example, type `Draft: ` and then choose Draft date. The variable is inserted at the cursor; you do not need to type its technical notation.

The preview shows how each area resolves the information. Script title follows the script's name, and Draft date follows the [title-page date setting](/editor/export/title-page/#choose-the-draft-date).

## Format the selected area

Use <img class="kb-editor-icon" src="/icons/editor/bold.svg" alt="" aria-hidden="true" /> **Bold**, <img class="kb-editor-icon" src="/icons/editor/italic.svg" alt="" aria-hidden="true" /> **Italic** or <img class="kb-editor-icon" src="/icons/editor/underline.svg" alt="" aria-hidden="true" /> **Underline** after selecting an area. The style applies to that area's content.

**Hide in editor** hides the selected area while you write. It does not remove it from exported PDF pages. Use this when you want a quieter writing view while retaining running information in the output.

Changes apply as you make them and are saved automatically for this script.

## Understand the reserved numbering areas

| Area | Purpose |
| --- | --- |
| Right header | **Page number**: the act–scene–page reference, shown in the settings preview as `I-1-1`. |
| Center footer | **Integrated page number**: the running page number, shown as `1.`. |

These areas have fixed content. You can change their styling or hide them in the editor, but their settings do not offer ordinary text editing.

Other editable areas offer **Page mark** alongside Script title and Draft date when you need the script reference there too. The settings preview uses sample page references; check the PDF for the actual numbers of your script.
