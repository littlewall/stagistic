---
title: Preview and download a PDF
description: Check your script's printable pages and download a PDF for rehearsal or sharing.
---

You want to send `The last door` to the cast. Start with the complete script and check its pages before handing it over.

## Prepare the PDF

1. Open the script and choose **Export** in the app header.
2. Under **Template**, choose **Basic**.
3. For the complete script, leave **Selected characters only** off in **Content**.
4. Wait for **Preparing preview** or **Updating preview** to finish.
5. Check the **PDF preview**, then choose **Download PDF**.

The downloaded file uses the script's title, for example `The last door.pdf`. Open the file in your PDF viewer to share or print it. The app header's **Download script** menu provides editable script files instead; see [Download a script file or package](/editor/scripts/download/).

## Save a draft or version with your PDF

When exporting **Current**, use **More download options** beside **Download PDF** to keep the script state you are sending:

1. Choose **Save as draft and download…** or **Save as version and download…**.
2. Optionally enter a draft **Reason**, or enter a version **Name** and optional **Note**.
3. Choose **Save draft and download** or **Save version and download**.

The editor saves the state and downloads the prepared PDF with its label in the filename. You stay in Current. Choosing **Download PDF** directly downloads the PDF without creating a draft or version.

To export an earlier state, select it in the state menu beside the script title, then choose **Export**. The preview uses its saved writing and settings, and the PDF filename includes its draft number or version name. You can adjust its Script settings for printing; those changes are saved to the selected state without changing Current.

See [Save drafts and versions](/editor/scripts/drafts-and-versions/) for revisiting, managing and restoring saved states.

## Move through the preview

- Scroll through the pages, or use <img class="kb-editor-icon" src="/icons/editor/previous-page.svg" alt="" aria-hidden="true" /> **Previous page** and <img class="kb-editor-icon" src="/icons/editor/next-page.svg" alt="" aria-hidden="true" /> **Next page**.
- To jump directly, enter a number such as `3` in **Page number** and press <kbd><span aria-hidden="true">⏎</span> Enter</kbd>. Leaving the field also applies the number.
- Use **Zoom out** (**−**) or **Zoom in** (**+**) to inspect the pages more comfortably. Preview zoom changes how you view the PDF, not the size of its printed text.

The Page counter counts pages in the PDF, including its opening pages and any inserted score pages. It can differ from a page reference printed inside the script.

## Check a changed output

Changing export choices or document settings prepares the PDF again. Wait until **Updating preview** has finished, inspect the new pages and then download.

An earlier preview may remain visible while the new PDF is being prepared. The availability of Download PDF alone does not confirm that your latest changes have finished updating.

If you see **Export preview failed**, the new output did not finish. Check the export choices and any score attachments before trying again; an older visible preview does not prove that the latest choices succeeded.

If the view says **Add script content to generate a PDF preview**, return to **Editor** and add some writing. A title or metadata alone does not provide script content for the preview.

## Include or omit notes

Expand **Content** and use **Show notes** to include or omit **Notes** blocks written in the script. This does not control the comment threads in the Comments panel.
