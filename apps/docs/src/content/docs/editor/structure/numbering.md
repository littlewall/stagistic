---
title: Customize scene numbering
description: Choose how automatic numbers appear before scene headings.
---

Scene numbers follow the order of scenes in your script. You do not need to type a number into `At the door` or update it manually after moving a scene.

## Choose a numbering style

1. In the app header, use <img class="kb-editor-icon" src="/icons/editor/settings.svg" alt="" aria-hidden="true" /> **Open script settings**.
2. Under **Block settings**, select **Scene**.
3. Change **Scene numbering** to the style you want.
4. Close settings to return to the script.

This setting applies to the current script. The choices are:

| Choice | Result before the heading |
| --- | --- |
| `1.` | A number followed by a dot, such as `2. Outside` |
| `1)` | A number followed by a closing parenthesis, such as `2) Outside` |
| No numbering | The heading text alone, such as `Outside` |

## What happens when scenes move?

After a [scene move](/editor/structure/rearrange/), numbers update to match the new order. Numbering runs through the whole script; adding an act does not restart it.

The number is separate from the heading's editable text. Type the title itself, such as `Outside`, rather than including a number that will become outdated.

## Hide numbers without removing structure

Choose **No numbering** to hide the number before headings in the script. The blocks remain Scene headings. The Structure sidebar still uses numbered entries to help you navigate.

Changing this setting does not rename scenes, move their content or change their place assignments.
