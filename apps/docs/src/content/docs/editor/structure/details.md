---
title: Manage scene details
description: Edit a scene's heading and assign the places where it happens.
---

Give `Outside` a clear heading and assign `Street` as its place. The heading is text in the script; places are shared entries you can assign to more than one scene.

## Change a scene's title

1. Find the scene in the **Structure** sidebar and click its title.
2. Edit the Scene heading in the script.

The sidebar follows the heading's text. Changing that text keeps the same scene and its assigned places.

## Open a scene's details

1. At the top of the Structure sidebar, use <img class="kb-editor-icon" src="/icons/editor/attribute-manager.svg" alt="" aria-hidden="true" /> **Open structure in attribute manager**.
2. In the manager's **Structure** view, select `Outside` from the scene list.

The selected scene's **Places** field shows its current assignments. Selecting a scene in this view lets you edit its details; edit the heading itself in the script.

## Create a place

If `Street` does not exist yet:

1. Switch to the manager's **Places** view.
2. Use <img class="kb-editor-icon" src="/icons/editor/add.svg" alt="" aria-hidden="true" /> **Create place**.
3. Enter `Street` in **Name**.
4. Confirm **Create place**.

Use a name different from existing places. Creating a place makes it available to select; it does not automatically assign it to a scene.

## Assign places to the scene

1. Return to **Structure** and select `Outside`.
2. Open **Places**, type `Street` to find it, then select the matching suggestion.
3. Repeat if the scene uses more than one place.

The selected places appear as tags. You can use `House` for both `At the door` and `Back inside` without creating separate place entries.

To remove an assignment, use the <span aria-hidden="true">×</span> **Remove Street** button on its tag. This removes the place from this scene, while leaving the shared place available for others.

## Rename a shared place

In the manager's **Places** view, select the place and change **Name**. Press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> or leave the field to finish editing. Assigned scenes refer to the same shared place, so they use the new name too.

This does not rewrite ordinary words in scene headings or stage directions. For example, renaming the place does not change `Robin and Alex step outside.`
