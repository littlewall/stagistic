Begin Robin and Alex's story with the working title `The door`. You can change the title and add acts or scenes as the story grows.

## Create a script

1. On the home screen, choose **New script**.
2. Enter `The door` in **Script name**.
3. Choose the initial structure:
   - **Multi-act:** starts with an Act heading and a Scene heading.
   - **One-act:** starts with a Scene heading, without an Act heading.
4. Choose **Create script**.

The editor opens the new script. Multi-act is selected by default. The choice gives you a starting structure; you can [add acts and scenes later](/editor/structure/add/).

If you leave the name empty, the script starts as **Untitled script**.

## Open an existing script

On the home screen, find its card and click the title or **Go to editor**. The editor opens that script for continued work.

To return to your library from the editor, use <img class="kb-editor-icon" src="/icons/editor/home.svg" alt="" aria-hidden="true" /> **Go to home** in the header.

## Try the example script

When your library is empty, the home screen offers **Create example script**. It creates an example in your library and opens it so you can explore the editor.

This action appears for an empty library after it finishes loading. Once you have scripts, use New script to start your own work.

## Start from a file

If you already have a `.stagistic` or `.stepkg` file, choose **Import script** on the home screen and follow [Import or restore a script](/editor/scripts/import/).
