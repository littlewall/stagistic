---
title: Delete a script
description: Remove a script from your library after keeping any file you need.
---

Delete a rehearsal draft when you no longer need it. This removes the whole script and its content from the library.

## Keep a file first

If you want to retain a restorable copy, open the script and [download a `.stepkg` package](/editor/scripts/download/#download-a-package-for-backup-or-transfer). Check that the file was downloaded, then return home.

## Delete the script

1. On the home screen, find the correct script card.
2. Open its <img class="kb-editor-icon" src="/icons/editor/script-actions.svg" alt="" aria-hidden="true" /> three-dot menu, **Open actions for The last door — rehearsal draft**.
3. Choose **Delete script**.
4. Check the title in the confirmation dialog.
5. Enter `delete me` in the confirmation field.
6. Choose **Delete script** to finish.

The script disappears from the library. The dialog's removal is permanent and cannot be undone in the app. A downloaded file remains a separate copy you can [import later](/editor/scripts/import/).

Choose **Cancel** before confirmation to keep the script.

## Remove part of a script instead

If you only want to remove a boundary between scenes or acts, see [Change or remove a heading](/editor/structure/headings/). Those operations keep the following writing; deleting a script removes the whole script.
