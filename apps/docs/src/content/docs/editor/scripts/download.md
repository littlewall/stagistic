Download a copy of `The last door` before transferring it to another device or keeping a snapshot of the current draft.

## Choose a format

| Format | What it keeps |
| --- | --- |
| `.stepkg` | The script, title-page data, settings, character and group details, scene and place details, music, attachments and comments. |
| `.stagistic` | The script in its text format and supported title-page text. It does not include the full metadata and attachment set of a package. |

Use `.stepkg` for a backup you can [import into the editor](/editor/scripts/import/) with its associated data. The downloaded package is a snapshot; keeping it does not update it when you continue editing.

## Download a package for backup or transfer

1. Open the script in the editor.
2. In the header, use <img class="kb-editor-icon" src="/icons/editor/download.svg" alt="" aria-hidden="true" /> **Download script**.
3. Choose **Script & metadata (`.stepkg`)**.
4. Wait for preparation to finish, then check the downloaded file.

The editor saves pending writing before building the package. Attached files are included in the package, so you can transfer it as one file. Keep it somewhere you can find again.

If preparation fails, a package may not have been downloaded. Confirm that the file exists before relying on it as your backup.

## Keep a text format copy

Use the same <img class="kb-editor-icon" src="/icons/editor/download.svg" alt="" aria-hidden="true" /> **Download script** control and choose **Script (`.stagistic`)**.

This downloads the current writing in Stagistic's text format. You can import that file later to create a new script. You do not need to write the syntax yourself to use this option.

For technical information about the format, see [Stagistic Syntax](/syntax/).

## Need printable pages?

For PDF output, page layout and title-page design, see [Pages and export](/editor/export/). A script file is for continued editing and storage; printable output is prepared through the export view.
