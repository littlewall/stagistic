---
title: Choose and change a block type
description: Give your text its role in the script and change the type of an existing block.
---

Use a block type to say what the text means. For example, `Robin opens the door.` belongs in a **Stage direction**, while `We should go.` belongs in **Dialogue** beneath Robin's name.

## Choose a type

1. Place the cursor in the block you want to write or change.
2. In the editor toolbar, open **Change block type**. The control displays the current type and its icon.
3. Choose **Stage direction** for the action, or the type you need.
4. Write your text.

The same control changes a block that already contains text. Its appearance and behavior follow the new type, including that type's casing rules. Check the result after changing a speaker name or a note into another kind of text.

## Which type should I choose?

| Type | Use it for |
| --- | --- |
| Character | The speaker's name above their speech. See [Choose who is speaking](/editor/characters/speakers/). |
| Dialogue | Spoken words, such as `We should go.` |
| Aside | A note about the delivery of a speech, such as `quietly`. |
| Stage direction | Action on stage, such as `Robin opens the door.` |
| Lyrics | Sung words. See [Music and lyrics](/editor/music/). |
| Notes | A separate notes block, rather than a speaker's dialogue. |
| Scene | A scene heading. See [Acts and scenes](/editor/structure/). |

Acts are managed as part of the script's structure; they are not offered in this type menu. Converting a Scene heading can require confirmation because it changes the scene's structure.

## Change types from the keyboard

With the cursor in a block, <kbd>Alt</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> cycles forward through the available types; add <kbd><span aria-hidden="true">⇧</span> Shift</kbd> to cycle backward. On macOS, use <kbd><span aria-hidden="true">⌥</span> Option</kbd> in place of <kbd>Alt</kbd>. Acts are excluded from this cycle.

The menu also shows the configured number shortcut for each type. See [Keyboard shortcuts](/editor/writing/shortcuts/) for the platform-specific modifier and default numbers.
