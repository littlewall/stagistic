---
title: Keyboard shortcuts
description: Find the keys for writing, changing block types and formatting text.
---

Use these shortcuts while the cursor is in the script editor. Some keys have different effects depending on the current block type and cursor position. Follow the linked guide when you need the full procedure.

## Continue and edit

| Keys | What they do |
| --- | --- |
| <kbd><span aria-hidden="true">⏎</span> Enter</kbd> | Continue, split text or act on an empty block. [Details](/editor/writing/flow/). |
| <kbd><span aria-hidden="true">⇧</span> Shift</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> | Continue a nonempty Dialogue or Lyrics block with the same type. [Details](/editor/writing/flow/#continue-the-same-speech). |
| <kbd><span aria-hidden="true">⇥</span> Tab</kbd> | Switch Dialogue or Lyrics to Aside, or switch Aside back. [Details](/editor/writing/dialogue/). |
| <kbd><span aria-hidden="true">⇥</span> Tab</kbd> | In Stage direction, add indentation, up to two levels. [Details](/editor/writing/stage-directions/#adjust-indentation). |
| <kbd><span aria-hidden="true">⇧</span> Shift</kbd> + <kbd><span aria-hidden="true">⇥</span> Tab</kbd> | In Stage direction, remove one indentation level. [Details](/editor/writing/stage-directions/#adjust-indentation). |

For the compact chooser opened by <kbd><span aria-hidden="true">⏎</span> Enter</kbd> in an empty Scene, Stage direction or Character block, use <kbd><span aria-hidden="true">←</span> Arrow left</kbd> and <kbd><span aria-hidden="true">→</span> Arrow right</kbd> to select a type, <kbd><span aria-hidden="true">⏎</span> Enter</kbd> to apply it, or <kbd>Esc</kbd> to close it. See [Choose what to write in an empty block](/editor/writing/flow/#choose-what-to-write-in-an-empty-block) for the difference between changing types and inserting another block.

## Change a block type

| Operation | macOS | Windows/Linux |
| --- | --- | --- |
| Cycle forward | <kbd><span aria-hidden="true">⌥</span> Option</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> | <kbd>Alt</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> |
| Cycle backward | <kbd><span aria-hidden="true">⌥</span> Option</kbd> + <kbd><span aria-hidden="true">⇧</span> Shift</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> | <kbd>Alt</kbd> + <kbd><span aria-hidden="true">⇧</span> Shift</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> |
| Choose a configured number | <kbd><span aria-hidden="true">⌃</span> Control</kbd> + the number key | <kbd>Alt</kbd> + the number key |

The default number assignments are:

| Key | Type |
| --- | --- |
| <kbd>1</kbd> | Scene |
| <kbd>2</kbd> | Stage direction |
| <kbd>3</kbd> | Character |
| <kbd>4</kbd> | Aside |
| <kbd>5</kbd> | Dialogue |
| <kbd>7</kbd> | Lyrics |
| <kbd>0</kbd> | Notes |

The **Change block type** menu displays your current assignments. To change the numbers, see [Customize your writing flow](/editor/writing/customize-flow/#assign-a-different-number-shortcut). Acts are excluded from the ordinary type menu and cycle. See [Choose and change a block type](/editor/writing/blocks/) for changing existing text.

On macOS, <kbd><span aria-hidden="true">⌥</span> Option</kbd> + <kbd><span aria-hidden="true">⇥</span> Tab</kbd> also switches directly between **Character** and **Stage direction**, or between **Dialogue** and **Lyrics**. You can make the same changes from the type menu on either platform.

## Format text

| Style | macOS | Windows/Linux |
| --- | --- | --- |
| Bold | <kbd><span aria-hidden="true">⌘</span> Command</kbd> + <kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>B</kbd> |
| Italic | <kbd><span aria-hidden="true">⌘</span> Command</kbd> + <kbd>I</kbd> | <kbd>Ctrl</kbd> + <kbd>I</kbd> |
| Underline | <kbd><span aria-hidden="true">⌘</span> Command</kbd> + <kbd>U</kbd> | <kbd>Ctrl</kbd> + <kbd>U</kbd> |

Use these with your words selected. See [Format your text](/editor/writing/formatting/) for toolbar icons and removing a style.

## Undo and redo

| Operation | macOS | Windows/Linux |
| --- | --- | --- |
| Undo | <kbd><span aria-hidden="true">⌘</span> Command</kbd> + <kbd>Z</kbd> | <kbd>Ctrl</kbd> + <kbd>Z</kbd> |
| Redo | <kbd><span aria-hidden="true">⌘</span> Command</kbd> + <kbd><span aria-hidden="true">⇧</span> Shift</kbd> + <kbd>Z</kbd> | <kbd>Ctrl</kbd> + <kbd>Y</kbd> |

## Character references

While entering a character reference in a Stage direction, <kbd><span aria-hidden="true">⏎</span> Enter</kbd> or <kbd><span aria-hidden="true">⇥</span> Tab</kbd> finishes the reference, and <kbd>Esc</kbd> cancels the unfinished one. These keys act on the reference rather than changing the whole block. See [Refer to a character in a stage direction](/editor/characters/references/) for suggestions and returning to ordinary text.
