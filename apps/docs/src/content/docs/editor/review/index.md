Find a passage, try a different line and keep an editing note beside it. For example, find Alex's `Wait for me.`, try `Give me a moment.`, then review the note `Could Alex sound less urgent?`

## Finding, changing and reviewing

The editor searches text within the open script. Comments stay attached to passages or blocks while you review them. Resolving a thread keeps it available as a completed note; deleting it removes the thread.

Keyboard actions depend on the field you are using. Each guide shows where to put the cursor before pressing a shortcut.

For finding a script in the home library, see [Find your scripts](/editor/scripts/find/). For navigation by acts and scenes, see [Acts and scenes](/editor/structure/).
