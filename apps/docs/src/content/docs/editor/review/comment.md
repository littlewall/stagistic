---
title: Add a comment
description: Attach an editing note to selected words or to a whole script block.
---

Leave `Could Alex sound less urgent?` beside Alex's line so you can return to the question during revisions.

## Comment on selected words

1. Select `Wait for me.` in the script.
2. Choose **Comment** in the toolbar that appears by the selection.
3. In the new card in **Comments**, write `Could Alex sound less urgent?`.
4. Choose **Comment** to submit it.

The note is attached to the selected passage. The Comments panel opens for the draft, and the linked text is marked in the script.

## Comment on the whole block

1. Place the cursor in Alex's Dialogue block.
2. Open <img class="kb-editor-icon" src="/icons/editor/block-actions.svg" alt="" aria-hidden="true" /> **Block actions** beside it.
3. Choose <img class="kb-editor-icon" src="/icons/editor/comment.svg" alt="" aria-hidden="true" /> **Add comment**.
4. Write your note and choose **Comment**.

This attaches the note to the block, rather than a selected range of words. Use it for feedback about the whole speech or stage direction.

## Start a comment from the keyboard

With a text selection in the script, use:

- **macOS:** <kbd><span aria-hidden="true">⌘</span> Command</kbd> + <kbd><span aria-hidden="true">⌥</span> Option</kbd> + <kbd>M</kbd>.
- **Windows/Linux:** <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>M</kbd>.

With a cursor and no text selected, the same shortcut starts a comment on the current block.

## Finish or cancel the draft

In the comment field, <kbd><span aria-hidden="true">⏎</span> Enter</kbd> adds a line to the note. To submit, choose **Comment** or use <kbd><span aria-hidden="true">⌘</span> Command</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> on macOS, or <kbd>Ctrl</kbd> + <kbd><span aria-hidden="true">⏎</span> Enter</kbd> on Windows/Linux.

Choose **Cancel**, or press <kbd>Esc</kbd> in the draft field, to discard the unfinished comment. Empty notes cannot be submitted.

The note is stored with the script. To take comments with the rest of your work, [download a `.stepkg` package](/editor/scripts/download/).
