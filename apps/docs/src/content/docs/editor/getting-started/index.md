## Where to find script settings

Use <img class="kb-editor-icon" src="/icons/editor/settings.svg" alt="" aria-hidden="true" /> **Open script settings** in the app header. These settings belong to the current script: they include its title page, page layout and block settings.

For **Next element** and **Shortcut** under Block settings, follow [Customize your writing flow](/editor/writing/customize-flow/). For the printed appearance and title page, see [Pages and export](/editor/export/), which is still being prepared.
