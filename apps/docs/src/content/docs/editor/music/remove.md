---
title: Unassign or delete music
description: Remove a musical placement for reuse, or delete the number from the music list.
---

You move `Time to go` to another part of the story. Unassign it to keep the number and score for use elsewhere. Delete it when you want to remove the number from the list too.

## Unassign a number for reuse

1. In the **Music** sidebar, find the placed number.
2. Use the broken-link button, <img class="kb-editor-icon" src="/icons/editor/unassign-music.svg" alt="" aria-hidden="true" /> **Unassign music**. For this number, its accessible label is **Unassign Time to go**.
3. Confirm **Unassign music**.

Its start and explicit end marker, if present, are removed from the script. The written blocks stay. The number moves to **Unassigned** with its details and attached PDF available for reuse.

[Place the existing number through `#`](/editor/music/add/#place-an-existing-number) at its new starting location.

The title pill's controls also offer <img class="kb-editor-icon" src="/icons/editor/unassign-music.svg" alt="" aria-hidden="true" /> **Unassign music**. The rail's start-marker menu offers the same action.

## Delete the number

1. Use <img class="kb-editor-icon" src="/icons/editor/attribute-manager.svg" alt="" aria-hidden="true" /> **Open music in attribute manager** and select the number in **Music**.
2. Use the <img class="kb-editor-icon" src="/icons/editor/remove.svg" alt="" aria-hidden="true" /> trash button, **Delete Time to go**.
3. Confirm **Delete**.

The number is removed from the music list. If it was placed, its music markers are removed too. Dialogue, Lyrics and stage-direction text remain in their blocks.

Its score is no longer associated with a number you can reuse from that list. If you want the number and score later, choose Unassign instead, or [keep a package backup first](/editor/scripts/download/).

## Change only the ending

Use [Reset music end](/editor/music/range/#return-to-an-automatic-ending), when offered, to remove an explicit ending and return to the automatically derived span. The number stays placed.

To remove only the PDF, use [Remove in the score slot](/editor/music/score/#remove-the-attached-pdf). This keeps the number and its placement.

Check the surrounding spans after unassigning or deleting a number: an earlier automatically ended span can extend farther when the next music start is removed.
