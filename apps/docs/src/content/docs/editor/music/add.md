---
title: Add music to a stage direction
description: Use `#` to place an existing musical number or create one while writing.
---

Robin turns toward the door and starts `Time to go`. Put the number in a **Stage direction** at the point where its music begins.

## Start a new number with `#`

1. In a Stage direction, write `Robin turns toward the door.`
2. Type `#`, then `Time to go`.
3. Press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> to finish the new title.
4. In **Add music**, review **Music title**, choose **Song** under **Type**, then choose **Add music**.

The music title becomes a pill in the stage direction, and the number appears as placed music in the **Music** sidebar. Its musical span starts at this block.

To continue the stage direction, click in its prose before the pill and resume typing. Finishing the title or the creation dialog does not automatically return typing focus to that prose. This confirmation finishes music entry; it does not create another script block.

## Place an existing number

If you have [created a number in advance](/editor/music/manage/#create-a-number-in-advance):

1. Type `#` in a Stage direction.
2. Type part of its name to narrow the suggestions.
3. Click the number you want, or use <kbd><span aria-hidden="true">↓</span> Arrow down</kbd> and <kbd><span aria-hidden="true">↑</span> Arrow up</kbd> to select a suggestion, then <kbd><span aria-hidden="true">⏎</span> Enter</kbd>.

The existing number is placed without opening the new-number dialog. Typing its exact unassigned name and confirming also reuses that number. Click the prose before the pill when you want to continue the stage direction.

## Why is a number missing from suggestions?

Suggestions contain **Unassigned** numbers. A number already placed in the script is not offered as another placement. To move its use elsewhere, [unassign it first](/editor/music/remove/#unassign-a-number-for-reuse), then place it at the new location.

A block can contain one music start. Use another Stage direction when you need another number to begin.

## Cancel music entry

Press <kbd>Esc</kbd> while entering a new title to discard that draft. Confirming an empty title also removes the draft without placing music. If Add music is open, choose **Cancel** to discard the new-number step.

Leaving a nonempty draft title field also finishes its entry: an exact unassigned match is reused, or Add music opens for the new number. Use <kbd>Esc</kbd> in the draft title when you want to cancel instead.
