A musical number has a name and a type, **Song** or **Instrumental**. Placing it in the script gives it a start and a musical span. **Lyrics** is the block type for the words a character sings.

For example, Robin starts `Time to go`, sings `The road is calling me.`, and Alex speaks `Wait for me.` while the music continues.

## A number, its placement and its words

A number can wait in the Music list as **Unassigned** until you place it. Its start and end describe where music accompanies the script. Lyrics and Dialogue describe how the words are delivered, so you can switch between singing and speaking within the same musical span.

For speakers and groups, see [Characters](/editor/characters/). For output with integrated scores, see [Pages and export](/editor/export/).
