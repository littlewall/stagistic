---
title: Refer to a character in a stage direction
description: Use `@` to insert a character reference, then continue writing the stage direction.
---

When a stage direction describes what a character does, you can insert their name as a character reference. For example, you want to write `Robin opens the door.`

## Insert a reference

1. Place the cursor in a **Stage direction** block where the character's name should go.
2. Type `@` to start entering a character reference.
3. Type `Robin`. To use a suggested name, click it, or select it with <kbd><span aria-hidden="true">↓</span> Arrow down</kbd> or <kbd><span aria-hidden="true">↑</span> Arrow up</kbd> and press <kbd><span aria-hidden="true">⏎</span> Enter</kbd>.
4. Press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> or <kbd><span aria-hidden="true">⇥</span> Tab</kbd> to finish the reference and return to ordinary text. If you used <kbd><span aria-hidden="true">⏎</span> Enter</kbd> to select a suggestion, press it once more, or use <kbd><span aria-hidden="true">⇥</span> Tab</kbd>.
5. Continue with `opens the door.` as ordinary text after the reference.

Finishing the reference leaves you in the same stage direction, ready to continue the sentence. It does not create a new block.

## Change a reference

Click an inserted character reference to edit its name. Finish the edit with <kbd><span aria-hidden="true">⏎</span> Enter</kbd> or <kbd><span aria-hidden="true">⇥</span> Tab</kbd> to return to ordinary text.

To rename a confirmed character across the script, use its **Name** field in the [attribute manager](/editor/characters/manage/). Editing the text of one reference is a local change and may stop it from matching that confirmed character.

## Cancel before finishing

Press <kbd>Esc</kbd> while entering a reference to remove the unfinished reference.

## Does a reference confirm the character?

Completing the text and confirming a character are separate actions. If you enter a new name, you can [confirm it from the Characters sidebar](/editor/characters/confirmation/).
