---
title: Work with character groups
description: Create a named group, select its members and use it as a speaker in your script.
---

A character group gives a set of characters a shared name. For example, you can create `ENSEMBLE` with Robin and Alex as members, then use that group name in a speaker block.

## Create a group

1. In the **Characters** sidebar, use <img class="kb-editor-icon" src="/icons/editor/attribute-manager.svg" alt="" aria-hidden="true" /> **Open characters in attribute manager**.
2. In the manager's Characters section, switch to **Groups**.
3. Use the <img class="kb-editor-icon" src="/icons/editor/add.svg" alt="" aria-hidden="true" /> **Create group** button.
4. Enter `Ensemble` as the group name and choose **Create group**.

The new group opens in the detail panel. Its name must be different from existing character and group names.

## Add members

1. Select the group in **Groups**.
2. Open **Members** and select Robin and Alex.
3. Add or remove members through the same control as the group changes.

The Members list contains confirmed characters. If Robin or Alex is missing, [confirm the character](/editor/characters/confirmation/) first.

A group can exist without members. In the editor's Characters sidebar, an empty group is marked **Empty**.

## Use the group in a speech

In a **Character** block, start typing the group name and select its suggestion. Continue with the speech as you would for an individual character.

The speaker block uses the group name. To list Robin and Alex directly in a particular block instead, use [multiple speakers](/editor/characters/multiple-speakers/).

## Change or remove a group

Use <img class="kb-editor-icon" src="/icons/editor/manage.svg" alt="" aria-hidden="true" /> **Manage group ENSEMBLE** in the sidebar, or select the group in the manager. You can change its **Name**, color and **Members**. Name changes are saved when you press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> or leave the field; <kbd>Esc</kbd> discards an unfinished name change.

To remove the group, use its <img class="kb-editor-icon" src="/icons/editor/remove.svg" alt="" aria-hidden="true" /> trash button and confirm **Remove**. This removes the group and its membership. Existing occurrences stay in the script as unconfirmed character names.
