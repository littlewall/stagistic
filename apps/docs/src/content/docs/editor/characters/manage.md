---
title: Manage characters
description: Create characters and edit their names, colors, outlines and vocal details in the attribute manager.
---

Use the attribute manager to keep the details of your confirmed characters together. You can open it from the editor's **Characters** sidebar.

## Open a character's details

1. In the Characters sidebar, find Robin in the confirmed character list.
2. Use the pencil button, <img class="kb-editor-icon" src="/icons/editor/manage.svg" alt="" aria-hidden="true" /> **Manage ROBIN**.

The attribute manager opens with Robin selected. You can also use <img class="kb-editor-icon" src="/icons/editor/attribute-manager.svg" alt="" aria-hidden="true" /> **Open characters in attribute manager** at the top of the sidebar, then select a character from the list. Search the list when you need to find a particular name.

If a name is still under **Unconfirmed**, [confirm it](/editor/characters/confirmation/) before editing its details here.

## Create a character

In the manager's **Characters** view, use <img class="kb-editor-icon" src="/icons/editor/add.svg" alt="" aria-hidden="true" /> **Create character** and enter the character's name. You can also use <img class="kb-editor-icon" src="/icons/editor/add.svg" alt="" aria-hidden="true" /> **Add character** from the editor's Characters sidebar.

Choose a name that is different from existing characters and groups. A created character is confirmed and available for suggestions, even before you write its first speech.

## Rename a character

1. Select the character in the manager.
2. Change **Name**.
3. Press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> or leave the field to save the change. Press <kbd>Esc</kbd> while editing to discard the unfinished change.

The rename updates occurrences linked to that confirmed character in the script. An ordinary name typed in prose is not a character reference; it is not part of this rename.

## Add details

- **Color:** use the color control beside the character's name. You can also change it from the sidebar.
- **Outline:** write a short description of the character.
- **Vocal details:** choose the voice type and vocal range when relevant to a musical script.

## Remove a character

Use the <img class="kb-editor-icon" src="/icons/editor/remove.svg" alt="" aria-hidden="true" /> trash button in the character's details, then confirm **Remove**.

This deletes the character record and its details, including color and outline. Its lines and blocks stay in the script, and existing occurrences become unconfirmed. The character is also removed from groups it belonged to.
