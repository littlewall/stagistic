title: Characters
description: Choose speakers, confirm characters, create groups and refer to characters while writing.

Characters connect a name in your script with the person who speaks or acts. Use a **Character** block above a speech to choose its speaker, or a character reference inside a **Stage direction** to name someone in the action.

You can start writing a new name immediately. [Confirming a character](/editor/characters/confirmation/) adds it to the character list where you can manage its details. A [group](/editor/characters/groups/) has its own name and a list of confirmed characters as members.

## What would you like to do?

- [Choose who is speaking](/editor/characters/speakers/) — start with Robin's name and continue with a speech.
- [Confirm characters](/editor/characters/confirmation/) — understand the Unconfirmed list and add details to a character.
- [Write dialogue for multiple characters](/editor/characters/multiple-speakers/) — add Alex to the same speaker block using `+` or `/`.
- [Work with character groups](/editor/characters/groups/) — give Robin and Alex a shared group name and manage its members.
- [Refer to a character in a stage direction](/editor/characters/references/) — use `@` to write what Robin does.
- [Manage characters](/editor/characters/manage/) — change a name, color, outline or vocal details.

Each guide can be read on its own. For the text of a speech and changing block types, see [Writing your script](/editor/writing/).
