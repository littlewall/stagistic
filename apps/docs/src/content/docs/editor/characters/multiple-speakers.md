---
title: Write dialogue for multiple characters
description: Add more than one speaker to a Character block using `+` or `/`.
---

When Robin and Alex share a speech, put both names in the same **Character** block above it.

## Add another speaker

1. In a **Character** block, enter `Robin` or choose Robin from the suggestions.
2. At the end of the name, type `+` or `/`.
3. Type `Alex`, or choose Alex from the suggestions for the next name.
4. Repeat the separator and name for any additional speakers.
5. Press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> at the end of the completed block to continue with the speech.

With the default casing, the speaker block reads `ROBIN/ALEX`. The editor keeps the names in the order you entered them.

## Should I use `+` or `/`?

Both start the next name. The editor converts a typed `+` into `/`; they do not represent two different kinds of shared speech. You do not need to add spaces around the separator.

This behavior applies to the names in a Character block. A `/` inside a parenthesized note is treated as ordinary text.

## Edit the names

Click back into the speaker block to change a name or remove one with its separator. Suggestions apply to the name at the cursor, so you can replace one speaker without re-entering the others.

## When to use a group

For a named set of characters that you want to reuse, such as `ENSEMBLE`, [create a character group](/editor/characters/groups/). A group has its own name and member list; entering `ROBIN/ALEX` puts the individual names directly in this block.
