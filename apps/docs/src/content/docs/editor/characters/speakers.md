---
title: Choose who is speaking
description: Enter a new speaker or select an existing character, then continue with their speech.
---

Put the speaker's name in a **Character** block above their dialogue. You can write a new name as you go; you do not need to create the character in advance.

## Enter a speaker

1. Place the cursor in a **Character** block. To change an existing block, use its block type control and choose **Character**.
2. Type `Robin`. With the default settings, character names appear in uppercase.
3. Press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> at the end of the name to continue in the next block. With the default settings, this is a **Dialogue** block.
4. Write Robin's speech.

If you have changed the next-block settings, <kbd><span aria-hidden="true">⏎</span> Enter</kbd> follows your configured block type.

## Reuse an existing character

Start typing a name in a Character block. When a matching suggestion appears, click it to insert the name. You can also use <kbd><span aria-hidden="true">↓</span> Arrow down</kbd> or <kbd><span aria-hidden="true">↑</span> Arrow up</kbd> to select a suggestion and <kbd><span aria-hidden="true">⏎</span> Enter</kbd> to accept it.

Accepting a suggestion fills in the speaker's name. Press <kbd><span aria-hidden="true">⏎</span> Enter</kbd> at the end of the completed name to continue with the speech.

## What happens to a new name?

A name that is not yet in your confirmed character list appears under **Unconfirmed** in the Characters sidebar. You can keep writing, or [confirm the character](/editor/characters/confirmation/) when you want to manage its details.

Finishing the speaker block with <kbd><span aria-hidden="true">⏎</span> Enter</kbd> and confirming a character are separate actions.
