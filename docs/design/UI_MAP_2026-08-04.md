# UI mapa — `apps/web`, 2026-08-04

Inventář povrchů webové aplikace pro komplexní UX/UI redesign. **Fakta, ne hodnocení** — hodnocení je v [`UX_FINDINGS_2026-08-04.md`](./UX_FINDINGS_2026-08-04.md).

## Rozsah a metoda

| | |
|---|---|
| **Rozsah** | Pouze `apps/web` a balíčky, které vykresluje (`app-routes`, `editor`, `ui`). Landing i desktop mimo. |
| **Metoda** | Čtení zdroje + živý průchod přes Playwright proti dev serveru na `http://localhost:3000` (PGlite v prohlížeči, bez backendu). |
| **Seed** | Prázdná knihovna (studený start) a scénář z `Create example script` — „One Small Light", 2 akty, 4 scény, 2 postavy, 1 hudební číslo, 8 stran exportu. |
| **Varianty** | Light + dark, šířky 1440 / 1200 / 1100 / 1024 / 1000, gate na 999. |
| **Snímky** | [`screens/2026-08-04/`](./screens/2026-08-04/) — prefix odpovídá toku (`f1-` … `f10-`). |

Zdrojem pravdy pro záměr je [`PRODUCT.md`](../../PRODUCT.md). `DESIGN.md` je zastaralý a **nebyl** použit jako měřítko.
