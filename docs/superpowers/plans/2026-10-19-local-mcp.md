# Local MCP Implementation Plan

Execution status: backend and both distribution paths implemented. Final evidence,
implementation adjustments and remaining actual-client/release smoke checks are
recorded in [local-mcp.md](../../testing/local-mcp.md). The original checklist
below remains the design outline, not a claim that unperformed manual checks passed.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for direct execution, or superpowers:subagent-driven-development if the user selects delegated execution. Steps use checkbox (`- [ ]`) syntax for tracking. Read the spec first. Never commit: the user reviews and creates every commit.

**Goal:** Zpřístupnit uložené lokální scénáře přes jeden nativní stdio MCP server, distribuovaný v `.mcpb` pro Claude Desktop i jako executable s hotovou ruční konfigurací.

**Architecture:** Jeden Rust program `stagistic-mcp` implementuje MCP a komunikuje přes UDS s Rust brokerem desktopu. Broker předává omezené požadavky hlavnímu WebView; samostatná read služba čte stejnou PGlite instanci jako editor a serializuje fragmenty společným Stagistic serializerem. MCPB a ruční cesta obsahují totožný podepsaný univerzální macOS executable.

**Tech Stack:** Tauri 3 alpha/Wry, Rust, oficiální MCP SDK `rmcp`, Tokio, serde, schemars, ts-rs, TypeScript, Ajv 2020, PGlite/Drizzle/PostgreSQL FTS, Moon, Vite+ tests, macOS signing tools, MCPB CLI.

**Spec:** [2026-10-19-local-mcp-design.md](../specs/2026-10-19-local-mcp-design.md)

## Global Constraints

- První platforma: macOS, Apple Silicon i Intel; release executable je univerzální. Žádný Node/Rust/runtime u uživatele.
- Claude je primární klient; jiní lokální klienti potřebují podporu stdio podprocesů. Bez nového UI, HTTP serveru a automatického spouštění aplikace.
- Pouze potvrzený lokální stav DB. Žádné mutace scénářů, outbox, autosave, změny aktivního bloku, cloud, vektory, modely, prompts ani skilly.
- Formát textu: Stagistic syntax. Fragment nese kontext; nepřidává smyšlené struktury a nemusí být samostatným `.stagistic` souborem.
- Požadavek interního protokolu nejvýše 16 KiB; úspěšná doménová odpověď 32 KiB; MCP zpráva nejvýše 64 KiB. Vždy UTF-8 bytes, nikoli počet JS znaků.
- Výchozí stránka 20, maximum 100; search maximum 50; query nejvýše 512 znaků; snippet nejvýše 240 znaků. Neplatný explicitní limit odmítnout, ne tiše změnit.
- U query/snippet znamená znak Unicode code point (Rust `chars`, JS `Array.from`), zatímco transportní rozpočty jsou vždy bajty UTF-8. Neřezat uprostřed surrogate páru.
- Timeout brokeru 10 sekund, nejvýše 8 aktivních požadavků společně pro všechny klienty. Pro UDS klienta použít 12sekundový celkový deadline jako rezervu na doručení chyby brokeru.
- Produkce `/tmp/stagistic-mcp-<uid>/run.sock`, vývoj `/tmp/stagistic-mcp-dev-<uid>/run.sock`; adresář `0700`, socket `0600`, OS lock po dobu listeneru.
- Integrace defaultně vypnutá. Zapnutí, vypnutí a export konfigurace jsou oddělené operace; instalace Claude také zapíná přístup. Export jej sám nezapíná.
- MCP stdout obsahuje pouze protokol. Logy neobsahují scénáře, dotazy, odpovědi, osobní cesty ani stack trace pro klienta.
- Změna FTS nevyžaduje bump `SCRIPT_DOCUMENT_SCHEMA_VERSION`. Po DB migraci spustit `moon run db:db-compile-migrations`.
- Všechny kontroly přes Moon. Needitovat generovaný root `vite.config.js`, baseline duplicity ani golden snapshots kvůli nesouvisejícím selháním.
- Žádný automatický commit, staging, publikování, instalace do skutečného Claude ani změna jeho configu. Ruční instalační smoke test provádí uživatel. Každá úloha končí připraveným diffem a návrhem zprávy pro uživatelův commit.

## Rozhodnutí o rozhraních

- Interní `PROTOCOL_VERSION = 1` je oddělený od MCP verze vyjednané SDK. Rust kontrakt serializuje pole v `snake_case`, neznámá pole a operace odmítá. ID je neprázdný opaque string, ne automaticky UUID: existují i ID typu `rw-scene:…`.
- `ReadOperation` je tagged union `{tool, arguments}` pro sedm nástrojů ze spec. Společné argumenty `limit?: number`, `cursor?: string`; `start_block_id` je pouze pro excerpt, `scene_id` volitelně pro search/dialogue, `block_type` volitelně pro search.
- `LocalRequest = {protocol_version: number, operation: ReadOperation}`. UDS má jednu JSON zprávu na connection; žádné JSON-RPC forwardování od klienta do Tauri.
- `ReadPage = {format, scope, revision, items, next_cursor, incomplete}`; `format` je `metadata | stagistic | plain_text`, `scope` je library nebo script s `script_id`. `items` je typovaná unie výsledků nástrojů; text existuje pouze jednou uvnitř textové položky. `next_cursor` je string nebo null, `incomplete = next_cursor !== null`.
- Textová položka nese skutečná `block_ids`, `scene_id`, `act_id`, `text` a `context` obsahující kontext serializeru. Metadata postavy obsahují `confirmed`, `character_id: string | null` a `character_key`. Nepotvrzenou postavu nelze vydávat za potvrzené ID.
- `McpReadError = {code, message, block_id?: string}` s kódy ze spec. `ReadReply` je `{ok: true, page: ReadPage}` nebo `{ok: false, error: McpReadError}`.
- `UiRequest = {generation: string, request_id: string, request: LocalRequest}`; `UiReply = {generation: string, request_id: string, reply: ReadReply}`. Generaci i request ID vytváří Rust, nikdy je nepřebírá od externího klienta.
- `McpReadService.execute(operation: ReadOperation, signal?: AbortSignal): Promise<ReadPage>`; očekávaná doménová selhání používají `LocalMcpReadError` s odpovídajícím payloadem. WebView mapuje ostatní výjimky na generický `INTERNAL_ERROR`.
- `McpAdminStatus = {enabled: boolean, ready: boolean, protocol_version: number, bridge_version: string}`; úspěšné předání MCPB vrací pouze `{status: 'installation_requested'}`. Administrační operace nejsou MCP tools.
