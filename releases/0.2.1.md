notes:
  - type: improvement
    title: Lines never start with a space
    highlight: false
    description: A line of the script never starts with a space or tab, whether you type, paste, split or join lines, so every line starts at its margin. Tab in a stage direction no longer indents it.
  - type: fix
    title: Renaming and confirming characters keeps their details
    highlight: false
    description: Renaming one of several characters in a cue keeps `/` between their names. Confirming a character that already exists keeps its colour, notes and other details.
  - type: fix
    title: Scripts come back intact from a .stagistic file
    highlight: false
    description: "Exporting a script to `.stagistic` and importing it again now keeps everything you wrote: `*`, `_`, `\\` and `@` typed as text, lowercase lyrics, all-caps dialogue, empty stage directions and character cues, the kind of a music number, character names with a colon, acts without scenes and a manual title-page date left empty. A broken file is reported instead of stopping the import. In older files, a `~` line right after lyrics now opens as an empty dialogue line, and several `~` lines in a row stay separate."
  - type: fix
    title: Damaged .stepkg files are reported
    highlight: false
    description: Importing a `.stepkg` package with damaged contents now shows a clear import error instead of an unexpected failure.
